## About

EXLIRIX Software is an independent studio building **Tessel.UI** — a pure, framework-free UI toolkit with a consistent, Fluent-inspired design language.

Rather than shipping one library and wrapping it for other ecosystems, each platform gets a genuinely **native** implementation — no bindings, no interop layer, no compromise on look, feel or performance. Same spacing and motion tokens, same component set, same light/dark theming — carried across three languages and three runtimes.
